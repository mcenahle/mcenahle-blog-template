#### 这是一篇示例博客文章。

本博客主题使用 [Astro](https://astro.build) 框架，并使用 [Bootstrap 3.4.1](https://getbootstrap.com/docs/3.4/)。

#### 简介

这是我自己开发并实际使用的 Astro 博客主题，提供文章页面、评论、搜索、文章地点信息等功能。

相关特色：

- Astro 静态生成；
- [Twikoo](https://twikoo.js.org/) 评论；
- 文章多地点显示；
- 支持 [Iconify](https://icon-sets.iconify.design/) 图标，默认支持 [mdi](https://icon-sets.iconify.design/mdi/) 图标；
- 年/月/日/文章编号 文章路由；
- [Pagefind](https://pagefind.app/) 全站搜索；
- [鸳鸯文楷体](https://github.com/lxgw/LxgwWenKai) 使用 [中文网字计划](https://chinese-font.netlify.app/zh-cn/) 进行 [分包](https://chinese-font.netlify.app/zh-cn/online-split/)。

#### 使用方法

1. `gh repo clone mcenahle/natsume`
2. `pnpm install`
3. `pnpm dev`
